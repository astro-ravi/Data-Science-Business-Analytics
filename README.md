## Tasks Overview

### Task 1: Prediction using Supervised ML
- **Goal:** Predict a student's marks percentage based on their daily study hours using simple linear regression.
- **Key Question:** What is the predicted score if someone studies for 9.25 hours a day?
- **Dataset:** [Download here](http://bit.ly/w-data)
- **Tech Used:** Python (pandas, matplotlib, scikit-learn)

### Task 2: Prediction using Unsupervised ML
- **Goal:** Find the optimum number of clusters in the Iris dataset and visualize the clustered results.
- **Approach:** Used the Elbow Method to find the best value for *k*, followed by standard K-Means clustering.
- **Dataset:** [Download here](https://bit.ly/3kXTdox)
- **Tech Used:** Python (numpy, pandas, matplotlib, scikit-learn)

### Task 3: Prediction using Decision Tree Algorithm
- **Goal:** Train a Decision Tree classifier on the Iris dataset to classify species accurately on new sample data, and visualize the resulting tree graph.
- **Dataset:** [Download here](https://bit.ly/3kXTdox)
- **Tech Used:** Python, Scikit-Learn, Matplotlib / Graphviz, Tableau
